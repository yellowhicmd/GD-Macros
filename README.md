# GD-Macros

A collection of downloadable macros to make tasks faster and easier.  

---

## Contents
- Organized macros stored in the `web/` folder
- Easy access through the live site
- Lightweight and ready to use

---

## Usage
1. Visit the [live site](https://gd-macros.pages.dev).
2. Browse the available macros.
3. Download and apply them to your workflow.
